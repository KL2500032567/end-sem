CSS and Its Types --------------------- CSS (Cascading Style Sheets) is a stylesheet language used to control the appearance, layout, colors, fonts, spacing, and responsiveness of HTML web pages. CSS separates the content (HTML) from its presentation (CSS). Basic CSS Syntax Example: Here: p → selector color and font-size → properties blue and 20px → values Types of CSS There are three main ways to apply CSS: 1. Inline CSS selector { property: value; } p { color: blue; font-size: 20px; } 2. Internal CSS 3. External CSS 1. Inline CSS In Inline CSS, the style is written directly inside the HTML element using the style attribute. Example Advantages Very easy to apply. Useful for styling a single HTML element. Quick for testing. Disadvantages Difficult to maintain for large websites. CSS and HTML become mixed. Cannot be easily reused. 2. Internal CSS Inline CSS
